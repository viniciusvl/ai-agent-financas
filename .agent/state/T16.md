## Última sessão (2)
- O que foi feito:
  - `BotService.__init__` implementado: guarda as dependências, `allowed_user_ids` como `set`
    e `clock` padrão `datetime.now(ZoneInfo(timezone))`.
  - `handle_update` nunca propaga exceção (`try/except` + `logger.exception`) e delega a
    `_dispatch`, que ignora updates sem `message` (edited_message, sticker, vazio).
  - Autorização para mensagens: fora da lista (lista vazia = ninguém) →
    `MSG_UNAUTHORIZED.format(user_id=...)` e nada mais.
  - Comandos `/start`/`/help` (aceitando `@NomeDoBot` via `_is_command`) → `MSG_HELP`.
  - `recebido_em`: `message.date` (unix, UTC) → `datetime.fromtimestamp(ts, tz=UTC)`; ausente →
    `clock()`.
  - Voz/áudio: `download_file` + nome `voice.ogg`/`audio.file_name` (fallback `audio.ogg`) +
    `transcribe`; envia `MSG_TRANSCRIPTION` (com `html.escape`) e segue com o texto transcrito;
    erro no download/transcrição → `MSG_TRANSCRIPTION_FAILED`.
  - Roteamento (`_process_text`): `router.route` com `RouterError` → `MSG_ROUTER_FAILED`;
    escrita (`extractor.extract` → `MSG_EXTRACTION_FAILED` / `MSG_NOT_EXPENSE` / pergunta /
    `store.save` + `format_confirmacao` + `confirmation_keyboard`); leitura
    (`read_agent.answer`, `ReadError` → `MSG_LEITURA_FAILED`); outro → `MSG_OUTRO`.
    Log INFO com intenção/origem/confiança, sem conteúdo do texto.
